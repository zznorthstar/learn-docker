# Roadmap

Highest value first.

1. **Real AI-client tuning.** Run sessions with Claude Code, Cursor and others; refine tool descriptions from how they actually behave.
2. **Relay hardening.** Rate limiting and/or Turnstile on `/ws`; a claim flow stronger than trust-on-first-use.
3. **Real device performance.** Measure Rive on real GPUs and phones; tune the adaptive detail mode.
4. **Live-Docker adapter.** Drive the same world from a real daemon through the typed action reducer.
5. **More worlds.** More Dockerfiles, Compose projects, registries; Kubernetes bridge scenarios.
6. **Rive depth.** Move image/volume/network lanes from SVG into Rive components.
